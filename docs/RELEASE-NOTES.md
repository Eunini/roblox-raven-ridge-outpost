Raven Ridge is an original alpine military-outpost environment, built as a new Roblox builder portfolio piece.

Included:

- `RavenRidge-Walkthrough.mp4`: 50-second walkthrough video, 1920×1080, 24 fps.
- `RavenRidge.rbxl`: native binary Roblox place. Open it in Roblox Studio.
- `RavenRidge.rbxlx`: editable native XML place.
- `SHA256SUMS.txt`: checksums for the three deliverables.

The environment has 5,835 anchored parts in 16 organized models, including four watchtowers, a fortified checkpoint, a command bunker with an operations interior, a helipad and original rotorcraft, a logistics yard and six-wheel truck, maintenance and personnel buildings, and an alpine landscape.

Native export structure checks, independent XML/binary round-trip checks, and Luau syntax checks passed. Browser verification covers camera navigation, the two architectural mechanisms, lighting, and mobile layout.

The video records the shared geometry in a browser renderer and is labeled accordingly. Roblox Studio is not available in the Linux build environment, so native rendering, player collisions, and runtime interaction behavior still require a Studio playtest. This is newly created portfolio work, not a previous client commission.
